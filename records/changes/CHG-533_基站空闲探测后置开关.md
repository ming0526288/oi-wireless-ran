# CHG-533 基站空闲探测后置开关

从 TEST-623 的门限 0 后置构建提取调度策略到 `openair2/LAYER2/NR_MAC_gNB/gNB_scheduler_ulsch.c`。基站初始化读取 `OAI_RESEARCH_PROBE_POLICY`。省略或填 `legacy` 沿用原顺序，`residual` 启用后置。无法识别的值在初始化时报告。两种模式共用同一个最小授权函数，沿用原 PF 的数据排序、重传处理和 SR 分配。

后置对象为已通过空闲门限、无 SR 且有效积压 `max(0, estimated_ul_buffer - sched_ul_bytes)=0` 的 UE。先完成常规分配，余下 UE 名额、PRB 预算、连续 PRB 符号掩码和 CCE 均满足时才发探测授权。连续 PRB 搜索保留原试验的末端边界。空闲门限、TDD、带宽和 UE 信令沿用基线。

已读 TS 38.321 V19.4.0（2026-09）§5.4.1、§5.4.2.2、§5.4.4、§5.4.5，TS 38.300 V19.4.0（2026-09）§10.3，TS 38.213 V19.5.0（2026-09）§9.2.4、§11.1，TS 38.214 V19.5.0（2026-09）§6.1.2.2。它们说明授权、重传、SR、BSR 和资源分配，具体先后顺序是基站实现选择。教材《5G移动通信系统设计与标准详解》§13.1.1.4–5（本地 PDF 537–539 页）用于核对 SR 与 BSR 的区别。《Dissecting 5G New-Radio Latency》§III–IV（本地 PDF 2–4 页）用于核对测量路径。

使用命令见根目录 `100MHz_门限0_命令.md`。结果见 [TEST-688](../tests/TEST-688_100MHz门限0后置开关核验.md)。本次三 UE 成功数据来自 RFsim，真实射频待现场联调。
