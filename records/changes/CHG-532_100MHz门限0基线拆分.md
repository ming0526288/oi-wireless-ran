100 MHz 等于 100,000,000 Hz，表示信道带宽。120 kHz 是子载波间隔，按 TS 38.211 §4.3.2，μ＝3 对应每 1 ms 8 槽，故槽长为 0.125 ms，5 槽周期为 0.625 ms。DDDSU 保留原配置。教材《5G移动通信系统设计与标准详解》已读 §4.2–4.3.1（本地 PDF 77–80 页）、§6.4.3（211–213 页）、§13.1.1.4–5（537–539 页）；测量和路径关联参考《Dissecting 5G New-Radio Latency》§III–IV（本地 PDF 2–4 页）。硬件驱动沿用原 DPDKRF。
